# Погода — виджеты погоды с картой

Веб-приложение, которое показывает текущую погоду, местное время и расположение на карте
для любой точки мира. Можно добавить несколько виджетов — по координатам, по названию
города или по своему местоположению.

**Демо:** https://ugurdurak3455-boop.github.io/weather-app/

**Репозиторий:** https://github.com/ugurdurak3455-boop/weather-app

## Возможности

### Основное
- **Погода по координатам.** Пользователь вводит широту и долготу — приложение показывает погоду в этой точке.
- **Карта.** В каждом виджете есть карта OpenStreetMap с маркером в выбранной точке и ссылка на большую карту.
- **Несколько виджетов.** Можно добавить до 12 виджетов, каждый со своей погодой и картой.
  Каждый виджет можно обновить или удалить.
- **Сохранение.** Список виджетов хранится в `localStorage` и восстанавливается после перезагрузки страницы.
- **Поиск города.** Вместо координат можно ввести название города — приложение найдёт его и добавит виджет.
- **Моё местоположение.** Кнопка подставляет координаты пользователя (Geolocation API).

### Данные в виджете
- температура и «ощущается как»;
- описание погоды (ясно, дождь, снег, гроза, туман и т. д.);
- **местное время в выбранной точке** (идут секунды) и дата;
- скорость и направление ветра (стрелка + сторона света);
- влажность;
- атмосферное давление в мм рт. ст.;
- минимальная и максимальная температура за день;
- время восхода и заката;
- часовой пояс и смещение от UTC;
- название места (определяется по координатам) и координаты.

### Дизайн
- **Разные изображения под разную погоду:** солнце, луна ночью, облака, дождь, снег, гроза, туман
  (анимированные SVG-иконки).
- Фон виджета меняется в зависимости от погоды и времени суток.
- Состояния загрузки и ошибки с кнопкой «Повторить».
- Адаптивная вёрстка (телефон, планшет, компьютер), учёт `prefers-reduced-motion`.

### Валидация ввода
- Широта — число от −90 до 90, долгота — число от −180 до 180.
- Пустые поля, буквы, лишние символы, экспоненциальная запись (`1e3`) не принимаются.
- Запятая автоматически заменяется на точку (`56,84` → `56.84`).
- Нельзя добавить второй виджет для той же точки и больше 12 виджетов.
- Название города: 2–80 символов, только буквы, пробелы, точка, апостроф и дефис.
- Ошибки показываются под соответствующим полем и исчезают при исправлении.
- Обрабатываются ошибки сети и сервера (понятное сообщение в виджете).
- Данные из `localStorage` тоже проверяются перед использованием.

## Технологии

- HTML, CSS, JavaScript (ES2020+) — **без библиотек и фреймворков**.
- Запросы через `fetch` и `async/await`, параллельная загрузка через `Promise.all`.
- Nginx + Docker для деплоя.

### Используемые API (ключи не нужны)
| Назначение | API |
|---|---|
| Текущая погода и прогноз на день | [Open-Meteo Forecast](https://open-meteo.com/en/docs) |
| Поиск города по названию | [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) |
| Название места по координатам | [Nominatim (OpenStreetMap)](https://nominatim.org/release-docs/latest/api/Reverse/) |
| Карта | встраиваемая карта [OpenStreetMap](https://www.openstreetmap.org/) |

### Устройство кода (`app.js`)
Код разделён на логические блоки, каждая функция решает одну задачу и занимает не больше 25 строк:

1. **Настройки** — адреса API, ограничения, константы.
2. **Коды погоды и иконки** — описание кодов WMO и SVG-иконки.
3. **Валидация** — `validateCoordinate`, `validateLocation`, `validateCityName`.
4. **Запросы к API** — `fetchJson`, `fetchWeather`, `fetchPlaceName`, `searchCity`.
5. **Форматирование** — температура, координаты, местное время, ветер; `toWeatherViewModel`.
6. **Карта** — `buildMapEmbedUrl`, `buildMapPageUrl`.
7. **Хранилище** — `loadSavedLocations`, `saveLocations`.
8. **Управление виджетами** — `addLocation`, `removeLocation`.
9. **Отрисовка** — `renderWidget`, `loadWidgetWeather`, `fillWidget`, обновление часов.
10. **Обработчики событий и инициализация** — `bindEvents`, `init`.

Погода в виджетах обновляется автоматически каждые 10 минут, местное время — каждую секунду.

## Запуск локально

Достаточно любого статического сервера, например:

```bash
cd public
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или открыть `public/index.html` прямо в браузере.

## Деплой

### Docker (рекомендуется)
На сервере с установленными Docker и Docker Compose:

```bash
git clone <ссылка-на-репозиторий> weather-app
cd weather-app
docker compose up -d --build
```

Приложение будет доступно на 80 порту: `http://IP-СЕРВЕРА/`.

### Nginx без Docker
```bash
sudo apt install nginx
sudo mkdir -p /usr/share/nginx/html
sudo cp -r public/* /usr/share/nginx/html/
sudo cp nginx/default.conf /etc/nginx/conf.d/weather-app.conf
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

Конфигурация nginx (`nginx/default.conf`) включает gzip-сжатие, кеширование статики
и базовые заголовки безопасности.
